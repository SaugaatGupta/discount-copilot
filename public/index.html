    Margin ROI = incremental margin ÷ restaurant-funded discount, measured against a no-discount control group. 1.0x is break-even.

    What this is

    A concept prototype of a GenAI sales-enablement tool. Sales reps ask questions in plain English. A Claude agent answers by calling three tools:

    • run_sql: read-only SQL over 50K orders, 60 restaurants and 45 campaigns
    • get_campaign_roi: measures each campaign against a control group (difference-in-differences)
    • simulate_offer: projects what a new offer would do before the rep pitches it

    Guardrails

    • Every number has to come from a tool result, and you can see each tool call under the answer
    • SQL is read-only, the agent has a step limit, and off-topic requests get declined
    • A 40-case eval harness checks accuracy (see the Evals tab)

    Data

    All restaurants, orders and campaigns are synthetic. They're generated to include realistic patterns, like deep discounts on high-value orders and discounts that mostly go to repeat customers. This project isn't affiliated with any company.
